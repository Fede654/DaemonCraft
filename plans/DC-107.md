## Root Cause

The "commitment problem" is unsolved: gateway promises things in chat ("I'll build that"), but never writes to the plan. Loop discovers nothing new on heartbeat.
→ **RESOLVED:** Gateway now auto-detects actionable intent and creates plan goals directly.

## Implementation

### Gateway side (`hermes-agent/gateway/platforms/daemoncraft.py`)

- `_maybe_mutate_plan_from_chat(player_message)`:
  1. Fetches current plan via POST `/action/plan` (action=get_plan)
  2. Returns early if plan already has a goal (no overwrite)
  3. Heuristic keyword detection on player message for actionable intent
  4. Creates plan via POST `/action/plan` with `action=set_goal`, sanitized goal text, and `expected_epoch`
  5. Called automatically after every handled chat message in `_handle_chat_entry`

### Daemon side (`daemoncraft/agents/daemoncraft.py` + `agent_loop.py`)

- `GATEWAY_HANDLES_CHAT` env var propagated to agent loop environment
- `GATEWAY_HANDLES_QUEST_EVENTS` env var also added for quest event ownership

- [x] @mention during loop action → loop interrupts → gateway responds

- [x] Self-echo filtered correctly
